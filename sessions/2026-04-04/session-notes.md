### 知识点2：地区产业结构变化

**学生初始理解**:
- 知道三次产业的大致划分
- 对“产业升级”有模糊印象，但尚未建立教材框架

**讲解内容**:
- 地区产业结构：一个国家或地区不同类型产业之间的比例关系
- 产业结构体现地区经济发展水平
- 升级的一般过程：劳动力从第一产业向第二、第三产业转移，国民经济重心由第一产业转向第二产业，进而转向第三产业
- 工业内升级的三种常见表现：轻纺工业 → 重化工业；原材料 → 加工组装；劳动密集型 → 技术密集型
- 产业升级的重要原因：比较优势的变化、政策的引导
- 从全球看，技术创新是推动产业不断升级的根本原因
- 深圳案例：第一产业 → 第二产业；由劳动密集型加工制造业为主升级为以高新技术产业和金融服务业为主
- 上海案例：第二产业主导 → 第三产业主导；轻纺工业 → 综合性工业 → 高新技术产业

**理解检查结果**:
- 经一次纠偏后，能准确说出“地区产业结构”定义和“是否属于产业结构变化”
- 能判断第一产业比重高通常说明经济发展水平较低，第三产业比重高通常说明经济较发达
- 能准确区分第一、第二、第三产业及典型行业
- 能说出产业结构升级一般过程和工业内部升级表现
- 对“比较优势的变化、政策的引导、技术创新”三者关系已基本理解，但在综合题中仍需再压实教材关键词

## 四、知识点总结

### 复习巩固的知识点

- **城市辐射功能逻辑链**：功能增强 + 交通改善 → 腹地扩大 → 四流集聚与扩散 → 辐射增强 → 带动周边
- **纽约对城市带辐射**：依托便利交通紧密联系，各城市分工协作，形成以服务业为主导且各具特色的产业体系
- **伊利运河作用**：运输更便捷，扩大腹地，促进纽约加速发展
- **武汉城市圈意义**：扩大武汉腹地，促进四流进一步集聚，增强武汉经济实力和核心带动作用

### 新学知识点

- **地区产业结构**：一个国家或地区不同类型产业之间的比例关系
- **体现发展水平**：第一产业比重高通常说明经济发展水平相对较低；第三产业比重高通常说明地区较发达
- **升级一般规律**：劳动力由第一产业向第二、第三产业转移；国民经济重心由第一产业转向第二产业，再转向第三产业
- **工业内部升级**：轻纺工业 → 综合性或重化工业 → 高新技术产业；低附加值劳动密集型 → 高附加值技术密集型
- **重要原因**：比较优势的变化、政策的引导
- **根本原因**：技术创新
- **深圳案例**：第一产业 → 第二产业；劳动密集型加工制造业 → 高新技术产业和金融服务业
- **上海案例**：第二产业主导 → 第三产业主导；轻纺工业 → 综合性工业 → 高新技术产业

### 记忆压缩句

- **看产业结构**：不是看“有没有”，而是看“谁占比更高、谁是主导”
- **看升级过程**：一产退、二产强、三产升
- **看升级原因**：比较优势在变，政策在引，根本动力靠创新
- **看深圳上海**：深圳更像“渔村起步后快速升级”，上海更像“老工业基地持续升级”
