## 学习内容

### 知识点 1: 生态修复分类复习

**学生初始理解**:
- 上次易混点是把“植树造林”误归为自然恢复，把“生态旅游/林下经济”误归为人工修复。

**讲解内容**:
- 自然恢复：减少人为干扰，让生态系统依靠自我调节恢复，如禁伐限伐、封山育林。
- 人工修复：采取生物或工程措施加快恢复，如植树造林、矿山覆土复绿。
- 社会经济转型路径：生态旅游、林下经济等，是修复后或保护中的发展方式，不属于自然恢复/人工修复分类。

**理解检查**:
- 问题：将禁伐限伐、封山育林、植树造林、矿山覆土复绿、发展生态旅游、发展林下经济分类。
- 学生回答：自然恢复：禁伐限伐、封山育林；人工修复：植树造林、矿山覆土复绿；社会经济转型路径：发展生态旅游、发展林下经济。
- 结果：✅ 完全正确。

**掌握程度**: 🟢 已掌握

### 知识点 2: 全球气候变化与人为碳排放

**学生初始理解**:
- 能认识到马尔代夫水下内阁会议“让人印象深刻”，但最初把主要威胁理解为海洋动植物难以生存。

**讲解内容**:
- 20世纪以来全球气候变化以变暖为突出特征，20世纪50年代以来增温更明显。
- 全球变暖趋势与大气中二氧化碳等温室气体浓度增加密切相关。
- 人为碳排放主要来自化石燃料燃烧和土地利用变化。
- 燃烧化石燃料增加二氧化碳排放；森林破坏减少植被吸收二氧化碳的能力。

**理解检查**:
- 问题1：为什么全球变暖会让马尔代夫这样的岛国面临国家安全问题？
- 学生回答：人为大量排放二氧化碳等温室气体 → 温室效应增强 → 全球气温升高 → 冰川融化、海水受热膨胀 → 海平面上升 → 低海拔岛屿和沿海低地被淹 → 居民迁移、环境难民、国家生存空间受威胁。
- 结果：✅ 因果链完整。
- 问题2：为什么“燃烧化石燃料”和“森林破坏”都会加剧全球变暖？
- 学生回答：多排碳 + 少吸碳 = 碳留在大气里更多 = 变暖更明显。
- 结果：✅ 核心正确，补充了规范表达。

**掌握程度**: 🟢 已掌握

### 知识点 3: 全球气候变化对国家安全的影响

**讲解内容**:
- 生存空间丧失：海平面上升导致低海拔岛国和沿海低地被淹。
- 加剧资源危机或自然灾害：水资源、耕地等战略资源减少或不稳定，旱涝、高温热浪等灾害加重。
- 激化国家间资源争端：资源短缺可能引发跨国争夺和多领域矛盾。
- 受其他国家波及而间接受影响：环境难民、国际资源市场价格波动等传导影响其他国家。

**理解检查**:
- 问题：全球气候变化可能从哪些方面威胁图瓦卢国家安全？
- 学生首答：只写出生存空间丧失链条。
- 引导补充：要求至少三点，从国土、资源、迁移与社会稳定展开。
- 学生复述：海平面上升 → 国土被淹 → 生存空间丧失，甚至被迫举国搬迁；海水入侵、土地盐碱化 → 淡水和耕地资源减少 → 饮水、粮食供应受威胁，资源危机加剧；居民被迫迁移 → 形成环境难民 → 社会稳定、国家主权延续和国际安置问题受到影响。
- 结果：✅ 纠正后完整。

**掌握程度**: 🟢 已掌握

### 知识点 4: 应对全球气候变化

**讲解内容**:
- 减缓措施：减少人为温室气体排放、增加温室气体吸收，目标是减缓全球变暖速度。
- 减排：降低能耗、使用清洁能源、改善产业结构、征收碳税、倡导节约消费。
- 增汇：减少森林破坏、植树造林、二氧化碳封存等。
- 适应措施：趋利避害，通过改变人类社会自身，降低全球变暖的不利影响或利用发展机遇。
- 国际合作重点：减缓、适应、资金、技术；坚持公平原则和共同但有区别的责任原则。

**理解检查**:
- 问题1：将推广风能太阳能、植树造林、修建海堤、调整作物结构、提高工业能效分为减缓/适应措施。
- 学生回答：减缓 ABE；适应 DC。
- 结果：✅ 正确。
- 问题2：为什么应对全球气候变化需要国际合作？发达国家和发展中国家分别承担什么责任？
- 学生回答：全球气候变化具有全球性影响，会导致海平面上升、极端天气等，单靠一国难以解决；各国都应参与减排和适应行动；发达国家排放多、资金技术强，应向发展中国家提供资金技术支持；发展中国家应根据本国国情参与减排和适应。
- 结果：✅ 得分点完整。

**掌握程度**: 🟢 已掌握

## 知识点详细梳理

### 复习巩固的知识点
- 生态修复分类：减少人为干扰让系统自己恢复 = 自然恢复；生物/工程措施人为加快恢复 = 人工修复；生态旅游和林下经济 = 社会经济转型路径。

### 新学知识点
- 全球气候变化最突出特征：全球变暖，20世纪50年代以来尤其明显。
- 人为碳排放与全球变暖：燃烧化石燃料增加排放，森林破坏减少碳汇，共同导致温室气体浓度升高。
- 对国家安全的影响：生存空间丧失、资源危机或自然灾害加剧、国家间资源争端、环境难民或资源价格波动等跨国传导。
- 应对措施：减缓和适应。
- 减缓：减排 + 增汇；适应：趋利避害、降低损失。
- 国际合作：坚持公平原则和共同但有区别的责任，重点关注减缓、适应、资金、技术。

### 记忆技巧
- 人为变暖：多排碳 + 少吸碳 = 碳留在大气里更多 = 变暖更明显。
- 气候变化影响国家安全：空间没了、资源紧了、争端多了、外部传来了。
- 应对气候变化：减缓治原因，适应减损失。
