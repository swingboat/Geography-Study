## 学习内容

### 一、外力作用四环节

**风化 → 侵蚀 → 搬运 → 堆积**

| 作用 | 做什么 | 记忆 |
|-----|-------|-----|
| 风化 | 把岩石在原地弄碎 | 碎 |
| 侵蚀 | 把碎屑物质带走 | 带 |
| 搬运 | 把物质运输到别处 | 运 |
| 堆积 | 物质沉积形成新地貌 | 积 |

**口诀**：碎→带→运→积

**学生表现**：
- 正确回答外力作用能量来源（太阳能、重力） ✅
- 能说出风化、侵蚀，但遗漏搬运和堆积 → 已补充学习

### 二、风化作用

三种类型：
1. **物理风化**：温度变化、冰劈作用
2. **化学风化**：水、CO₂与岩石反应（喀斯特基础）
3. **生物风化**：植物根系、动物活动

**学生表现**：
- 正确判断沙漠岩石崩裂是物理风化 ✅
- 正确判断喀斯特与化学风化关系 ✅

### 三、侵蚀作用

五种主要营力：
| 营力 | 典型地貌 |
|-----|---------|
| 流水 | V形谷、峡谷、瀑布 |
| 风力 | 风蚀蘑菇、雅丹地貌 |
| 冰川 | U形谷、冰斗、角峰 |
| 海浪 | 海蚀崖、海蚀柱 |
| 溶蚀 | 溶沟、溶洞、峰林 |

### 四、喀斯特地貌（重点讲解）

**形成条件**：
- 可溶性岩石（石灰�ite岩）
- 含CO₂的水
- 化学反应：CaCO₃ + H₂O + CO₂ → Ca(HCO₃)₂

**地表喀斯特**：溶沟、石芽、峰林、峰丛、洼地
**地下喀斯特**：溶洞、石钟乳、石笋、石柱

**石钟乳 vs 石笋**：
- 石钟乳：洞顶向下生长
- 石笋：洞底向上生长
- 相连形成石柱

**学生表现**：
- 正确回答桂林峰林是溶蚀形成 ✅
- 正确回答石钟乳从上往下长 ✅

### 五、搬运与堆积作用

**搬运特点**：
- 流水：分选性好（大颗粒先沉积）
- 风力：只能搬运细小颗粒
- 冰川：大小混杂，无分选

**堆积地貌**：
| 营力 | 地貌 | 例子 |
|-----|-----|-----|
| 流水 | 冲积扇、三角洲 | 黄河三角洲 |
| 风力 | 沙丘、黄土高原 | 塔克拉玛干 |
| 冰川 | 冰碛丘陵 | 北欧湖泊 |

**冲积扇 vs 三角洲**：
- 冲积扇：河流出山口，坡度变缓
- 三角洲：河流入海口，流速减慢

### 六、综合应用：黄河沿途地貌

**学生表现**（最终理解检查）：
- 上游峡谷 → 流水冲刷（侵蚀） ✅
- 中游冲积扇 → 坡度变缓，流速骤降（堆积） ✅
- 下游三角洲 → 流速减慢（堆积） ✅

不仅答对类型，还准确说出成因！
