## 🚀 快速开始

### 第一步：打开项目

在 VS Code 中打开此文件夹，确保已安装 **GitHub Copilot** 扩展。

### 第二步：开始学习

打开 Copilot Chat（快捷键 `Cmd+Shift+I` 或点击侧边栏图标），然后像和老师对话一样提问：

```
💬 "什么是热力环流？"
💬 "帮我讲讲农业区位因素"
💬 "地球自转有哪些地理意义？"
```

### 第三步：互动学习

AI 导师会：
1. **先问你**：了解你对这个知识点已经知道多少
2. **简洁讲解**：用约200字解释核心概念
3. **检查理解**：问你1-2个问题确认掌握
4. **适应调整**：懂了就深入，不懂就换方式再讲

## 🎓 学习方法：苏格拉底式引导

这个项目采用**引导式学习**，而不是直接灌输知识：

| 传统学习 | 引导式学习 |
|---------|-----------|
| 直接给答案 | 先问你知道什么 |
| 一次讲很多 | 每次约200字 |
| 讲完就结束 | 讲完要检查理解 |
| 不懂就跳过 | 不懂换方式再讲 |

**为什么这样更有效？**
- 建立在你已有的知识基础上
- 主动思考比被动接受记得更牢
- 及时发现并填补知识漏洞

## ❓ 常见问题

**Q: 我可以直接问问题吗？**
A: 当然可以！直接在 Copilot Chat 里提问就行，AI 会引导你学习。

**Q: AI 会直接给我答案吗？**
A: 不会直接给答案，而是先问你知道什么，然后引导你理解概念。

**Q: 怎么查看我学了哪些内容？**
A: 打开 [progress/geography-study-tracker.md](progress/geography-study-tracker.md) 查看。

**Q: 可以用其他 AI 吗？**
A: 可以！本项目同时支持 GitHub Copilot 和 Claude，都配置了相同的教学指令。
